# Worst Fix Ever: Funniest Commit Message

Entry for the make.fun bounty [Worst Fix Ever: Funniest Commit Message](https://make.fun/bounty/u-deysumbrella-worst-fix-ever-funniest-commit-message-3f1d9722).

## The entry

```
fix: memory leak fixed by deleting all user data every night at 3am
```

## How it works

`main.py` writes the single commit-message line above to `/output/entry.txt`
(the gate requires UTF-8 text of 1 to 100 characters). Run it with:

```
python3 main.py
```
